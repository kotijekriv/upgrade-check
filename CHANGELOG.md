# Changelog

## 0.1.0 — 2026-10-09

First experimental GitHub release.

- Read the current QGIS profile and choose an explicit target version.
- Compare exact package names against official repository declarations.
- Distinguish listed stable/experimental/deprecated releases, incomplete metadata, unknown packages, bundled components and missing saved references.
- Flag older target release numbers and conflicts between local and indexed metadata.
- Export HTML/JSON or copy a plain-text report.
- Read-only operation; no telemetry, plugin changes or runtime-compatibility promise.

Tested QGIS host: 3.44 on macOS. Official catalogue submission is pending; support is through GitHub Issues.
