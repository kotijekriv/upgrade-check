# Upgrade Check 0.1.0 — experimental

QGIS 3.44: **Plugins → Upgrade Check → Upgrade Check…** → choose a target version → **Check this profile**. Select a row to read the notes; save HTML/JSON or copy plain text.

This is a read-only report of official-repository declarations, not runtime compatibility. It never installs or changes plugins. Unknown, experimental, bundled and missing-reference states remain explicit. Read the author's page before migrating; an older target release is not a downgrade recommendation.

Only current/target QGIS version numbers are sent to `plugins.qgis.org`. Your plugin names and reports stay local. There is no telemetry. Reports may contain private plugin names; review them before sharing.

Tested on QGIS 3.44 for macOS. Windows and Linux QGIS hosts are untested. This release runs inside QGIS 3.x, not QGIS 4; you can select a QGIS 4 target for a declaration check.

Installable packages and full instructions: https://github.com/kotijekriv/upgrade-check

Support and feedback: https://github.com/kotijekriv/upgrade-check/issues

Distributed through GitHub; not yet listed in the official QGIS plugin catalogue. Catalogue contact metadata will be completed before submission.
